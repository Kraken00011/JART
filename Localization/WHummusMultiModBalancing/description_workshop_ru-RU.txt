[h2]A mod that utilises tPackBuilder to create as cohesive an experience possible between the Thorium and Calamity mods![/h2]

[h3]Changes include:[/h3]
[*] Modifying item recipes to fit into Calamity progression
[*] Adding recipes to keep Thorium and Calamity recipes consistent
[*] Balance changes to Vanilla, Thorium and Calamity weapons with the aim to make every weapon viable and fun to use for when they are available

[h3]ВАЖНОЕ ПРИМЕЧАНИЕ:[/h3]

[*] Added a text warning on start-up warning to turn off Ragnarok Mod's «Generic Weapon Tweaks» config, since if they are on, the balance changes from this and that mod stack in unintended ways. This message in question can be turned off in configs of this mod too
[*] As well as this in Ragnarok Mod's configs, Calamity Bard & Healer deduplication needs to be set to off for certain armors to be correctly craftable
